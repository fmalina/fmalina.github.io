Grid level optimisation for water, wind, waves, waste and solar

Glowwws offers energy generating asset operators, including small-scale operators, an innovative solution to efficiently manage their assets, optimise energy production, enhance grid stability, and reduce wastage. By leveraging real-time monitoring, data analysis, and advanced decision-making capabilities for dynamic dispatch, Glowwws empowers operators to maximise efficiency, reduce costs, increase revenue potential, and contribute to a sustainable and reliable energy grid ecosystem.


Preliminary Implementation Architecture (simplified representation)

Technology Description

Standard Python/Django ReST app with a web user interface - Architecture Components:

  • NGINX: Web server fronting the Django app
  • Relational DB: Database for storing project data (via ORM)
  • RESTful API for communication with Glows Monolith
  • IoT: Modular communication protocols to assets/devices for state monitoring and dispatch
  • Regular cron runs: Optimisation runs running several times per time period, this can be task based
